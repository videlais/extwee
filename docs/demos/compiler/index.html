Example Extwee Story Format Compiler

Compile Twee code with different Twine story formats

📝 How to Use

  1. Select a Story Format: Choose from Harlowe, SugarCube, Snowman, or Chapbook
  2. Enter Twee Code: Write or paste your Twee story code in the text area
  3. Compile: Click the "Compile Story" button to generate the HTML output
Example Twee Code:
:: Start
This is the beginning of your story.

[[Continue to the next passage->Next]]

:: Next
This is the second passage of your story.

The End.

Similar to Twine, this page will automatically assign an IFID to your story.

📄 Compiled Output

Select a story format and enter Twee code, then click "Compile Story" to see the output here.
About This Demo

This demo uses the Extwee web build to compile Twee code with story formats loaded dynamically from the Story Formats Archive.
