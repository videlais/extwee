# Extwee Config File Options

At a top level, the configuration file uses three properties:

```json
{
    "storyFormat": {},
    "input": {},
    "output": {}
}
```

## `storyFormat` Object

Two properties are possible:

```json
{
    "storyFormat": {
        "name": "name of story format to search for",
        "version": "exact version or word 'latest'"
    }
}
```
